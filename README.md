# VOSC Activity 1

A simple and responsive Tic-Tac-Toe game built using HTML, CSS, and JavaScript. This project was created as a basic web development activity.

## Project Overview

This game allows two players to take turns marking the board with X and O. It detects a winner, identifies a draw, highlights the winning combination, and lets the players restart the match at any time.

## Features

- Two-player Tic-Tac-Toe gameplay
- Real-time turn tracking
- Win detection for all standard combinations
- Draw detection when the board is full
- Restart button to reset the game instantly
- Clean and responsive UI for desktop and smaller screens

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Open the project folder.
2. Double-click on `index.html` in the file explorer.
3. The game will open in your browser and is ready to play.

## Project Structure

- `index.html` – page structure and game board
- `style.css` – styling and layout
- `script.js` – game logic and interaction handling

## Notes

This is a beginner-friendly project intended to demonstrate core front-end development concepts in a simple and interactive way.
